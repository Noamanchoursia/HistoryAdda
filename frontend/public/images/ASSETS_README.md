## Replacing placeholders

Replace the following files with owner-approved images while retaining their names and dimensions/aspect ratios:

- `founder/portrait.webp` — portrait / vertical composition
- `founder/group.webp` — group photograph
- `walk-03/cover.webp` — heritage architecture / walk cover

Use real, permission-cleared photographs. Do not publish identifiable participants, especially children, without permission. Add only verified captions and alt text.
